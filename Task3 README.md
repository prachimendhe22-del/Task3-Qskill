# Task 3: Matrix Operations Using NumPy

## Objective

To perform basic matrix operations using Python and NumPy.

## Technologies Used

* Python
* NumPy

## Operations Performed

1. Matrix Addition
2. Matrix Subtraction
3. Matrix Multiplication
4. Matrix Transpose
5. Matrix Determinant

## Description

This project demonstrates basic mathematical operations on two matrices using the NumPy library in Python.

## How to Run

Install NumPy:

`python -m pip install numpy`

Run the program:

`python Task3/matrix_operations.py`

## Learning Outcomes

* Understanding NumPy arrays.
* Performing matrix operations.
* Calculating matrix transpose and determinant.
